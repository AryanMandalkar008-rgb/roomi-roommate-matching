rROOMI SETUP

Connect your Roomi database.

This site is online-only. Add the Supabase project URL and publishable key to the Vercel project environment, then redeploy.

  1. Create a Supabase project and run supabase.sql.
  2. Add VITE_SUPABASE_URL and VITE_SUPABASE_ANON_KEY to Vercel.
  3. Redeploy the app so its account and data buttons can connect.
